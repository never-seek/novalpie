# NovalPie 原生 Android 2.0 Beta 4

NovalPie 2.0 是面向 [novalpie.cc](https://novalpie.cc) 用户的原生 Android 客户端。它不是把桌面网页简单套进一个浏览器：收藏、发现、书籍详情、论坛、个人页、阅读器和下载流程均以 Kotlin + Jetpack Compose 原生界面运行；只有登录安全验证及少数尚未原生化的网页能力才会使用已登录的网页回退。

本版是 2.0 的公开测试发布。它保留源站账号、权限、积分和内容规则，不提供第三方书源抓取、绕过收费或绕过网站权限的功能。

源码分支：[codex/native-app2-current-20260821](https://github.com/never-seek/novalpie/tree/codex/native-app2-current-20260821)。

## 这是什么

- 一个以手机阅读、书架管理和论坛交流为核心的 NovalPie 原生客户端。
- 一个直接适配源站接口和阅读会话协议的 Android 应用，而不是电脑网页缩放版。
- 一个仍在持续完善的 Beta：核心功能已经可用，但源站接口、Cloudflare 验证、网络环境和大体量作品仍可能带来变化。

## 2.0 核心能力

### 收藏、书架与发现

- 同步源站收藏分组、书籍封面、作者、名称、标签、收藏数、阅读量和字数等信息。
- 书架支持列表、分组、选择管理和每行 2 / 3 / 4 本的网格密度；作品名称、作者与阅读进度会保留，不以纯封面墙替代信息。
- 显示最近阅读和章节进度，可识别作品更新后“已读章节 / 最新章节”的变化。
- 搜索页在未输入关键字时也会加载默认作品；支持源站的搜索范围、内容分级、来源、搜索模式、排序与标签/规则筛选。
- 封面和书内图片保留原始图片能力；静止长按才会打开大图，滑动不会被误判为预览。

### 书籍详情、目录与书评

- 书籍详情将简介、目录、书评等内容分区展示，提供作品信息、完整标签、章节入口与继续阅读。
- 章节目录与网站同步，阅读记录由应用保存并用于回到当前章节。
- 书评、讨论与章节评论支持源站的点赞、点踩、表情、打赏、回复和展开嵌套回复等交互（是否可操作仍由登录状态和源站权限决定）。
- 剧透内容默认按源站规则遮罩；点按遮罩可单独展开，不会把“显示剧透”错误扩散到不相关页面。

### 原生阅读器

- 支持连续滚动、无限滚动和翻页阅读；到章节边界时可继续进入下一章或回到上一章末尾。
- 提供目录、章节导航、阅读进度、正文搜索/全文替换、字体、字号、行距、边距、主题、背景、图片显示等阅读设置。
- 翻页模式支持无动画、淡入、覆盖、滑动和仿真效果；阅读时可用音量键前后翻页。
- 工具栏采用点按正文显示/隐藏的阅读器交互，避免双击、滑动和返回键相互抢事件。
- 正文插图、动态图和 Animated WebP/GIF 会通过统一图片加载器显示；长按插图可进入缩放、拖动、双击复原的大图预览。

### 原生下载

- EPUB 与 TXT 都由 App 在本地生成并保存到 Android 下载目录，不会把下载流程踢回网页。
- EPUB 保留章节正文中的图片出现次数、原始图片字节和媒体类型，包含标准封面页、目录、章节 XHTML 与 OPF/导航结构。
- 下载前可选择图片并发数（含自定义值）；大图书会使用临时文件和完成后再发布的流程，避免直接写入下载目录时中断留下半成品。
- 如果作品下载需要源站积分或确认，仍会先显示源站对应的确认信息；请自行确认积分消耗、网络流量和设备可用空间。

### 论坛与交流内容

- 支持公告、推书、交流、书评、反馈等论坛分区、帖子详情、评论树和回复。
- 富文本原生显示普通文字、加粗、站内/站外链接、黑幕剧透、书籍分享代码和 Markdown/HTML 图片。
- `[bookid:书籍ID]` 会加载为可点开的原生书籍卡片，而不是裸代码。
- `![](...)`、`![说明](...)`、`<img data-src>` 与 `<img src>` 会作为原生图片块异步加载；图片下方的正文和互动按钮不会丢失，长按可查看大图。

### 我的、装扮、上传与管理

- 个人页同步动态、上传作品、评论/书评、签到统计与公开资料；头像框、徽章和背包装扮使用源站提供的视觉资源。
- 作品上传、EPUB 编辑、书籍信息和章节管理保留原生入口；管理员专属项目会根据当前账号权限显示或隐藏。
- 消息、工作区、设置等工具页仍可通过底部导航进入；需要网页登录或安全验证的场景会使用回退页保持源站登录流程。

## 网络、账号与数据说明

- App 连接 NovalPie 源站接口，内容、积分、评论权限、成人内容权限和管理员权限都以网站账号为准。
- 可在应用设置中配置代理；MuMu 等模拟器可通过 `adb reverse tcp:7890 tcp:7890` 使用主机本地代理。真实手机请填写可实际访问的代理地址，不会默认尝试模拟器回环地址。
- 升级安装会尽量保留登录态、收藏、阅读进度、搜索设置和已下载文件；不要为了“刷新”而随意清除应用数据。
- 若 Android 提示签名不一致，先备份重要本地数据后再处理。直接卸载旧包可能会清除本机阅读记录、会话与草稿。

## 本次发布包含的重点修复

- 修正超大 EPUB 写入下载目录时的临时文件/完整性校验流程，降低大文件复制中断后留下不完整文件的概率。
- 保留 EPUB 正文图片的每一次出现，不按图片哈希删除作者原文中本来就存在的重复插图；同时补全独立封面页与标准 EPUB 元数据。
- 修正论坛评论中的书籍分享卡片、Markdown/HTML 图片、黑幕、长链接与嵌套回复渲染。
- 修正封面/插图长按过快触发的问题：需要稳定长按，发生滑动会取消预览。
- 持续修正阅读器翻页、音量键、目录定位、无限滚动、系统栏、下载、个人动态和公开主页数据同步。

## 安装与反馈

1. 下载本 Release 中的 `NovalPie-native-2.0.0-beta4-debug.apk`。
2. 在 Android 系统允许当前来源安装 APK 后安装或覆盖安装。
3. 首次打开后按源站正常登录；遇到 Cloudflare/安全验证时按网页回退流程完成验证，再回到 App 刷新页面。
4. 发现问题时请尽量提供：作品/帖子链接、操作步骤、截图、设备型号、Android 版本和网络/代理情况。

这是 debug 签名的公开测试包，不是应用商店正式签名包。它适合已有 NovalPie 账号、愿意参与 2.0 回归与反馈的用户；源站服务变更、外部图片站失效、第三方 EPUB 阅读器兼容性等仍需要持续验证。
