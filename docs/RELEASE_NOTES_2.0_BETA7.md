# NovalPie 原生 Android 2.0 Beta 7

本次更新重点上线了 1:1 原生下载实时监控面板与控制台，完善了插图下载的指数退避重试与失败容错决策机制，彻底根治了超长篇幅小说的下载超时问题，规范了装扮中心与仓库卡片排版，并全面修复了正文阅读器在连续无限滚动下的翻页边界检测与进度追踪。

## 更新内容

- **原生 1:1 下载实时监控面板与终端控制台**：
  - 复刻原生沉浸式下载面板，提供大尺寸进度条、实时百分比动画，以及“正在下载章节（当前/总数）”与“正文插图（当前/总数）”的双维度指标展示。
  - 引入底部深色等宽控制台（Console）日志平滑滚屏，实时打印网络请求与打包流程，带有高亮色彩区分状态：`[DOWNLOAD]`（青色）、`[RETRY]`（黄色）、`[PACK]`（品红）、`[SUCCESS]`（绿色）与 `[ERROR]`（红色），让下载进度与图片拉取过程完全透明、一目了然。
- **插图与网络资源指数退避重试（Exponential Backoff with Jitter）**：
  - 针对网络波动、CDN 丢包或弱网环境，新增网络图片与插图抓取的智能重试机制（单资源最多 5 次重试，退避区间 400ms ~ 6s 并加入随机抖动），显著提升弱网环境下插图下载成功率。
- **下载失败智能决策流程（二选一卡片，全成功免打扰）**：
  - **免打扰打包**：若全部章节与图片均成功下载，自动直接流式打包出书，无需用户额外确认。
  - **失败二选一决策**：若在 5 次重试后仍有部分插图或封面因网络阻断/源站资源失效而下载失败，下载面板将安全挂起并弹出醒目的交互卡片，提供明确的二选一方案：
    - **【换个网络后重试】**：允许用户切换 Wi-Fi/移动网络或调整代理节点后，无缝继续重试失败的资源，无需重头下载；
    - **【直接打包】**：容错跳过不可达的残缺图片，直接利用当前已就绪的全部正文章节与完好图片进行 EPUB 流式打包与发布，确保读者在源站个别图源失效时也能正常获得完整的正文阅读书籍。
- **原生下载压缩控制与参数配置**：
  - 原生下载体系新增插图压缩开关，导出 EPUB 时支持对正文插图进行等比缩放与画质采样压缩，显著缩减文件体积。
  - 新增插图压缩质量（1% ~ 95%）与 ZIP 压缩等级（0 ~ 9）自由配置，支持并发度调节，参数通过持久化存储保存，开箱即用。
  - 个人中心【账号】页新增原生下载设置卡片，提供直观的开关与滑块控制。
- **超长小说导出稳定性增强**：
  - 优化大体量长篇小说的流式拉取机制，提升连接容限与传输稳定性，彻底解决数千章节大体量正文下载时的超时中断问题。
- **EPUB 流式打包与资源归档**：
  - EPUB 归档流全面支持动态 Deflate 压缩等级，正文章节与媒体资源打包效率更高、内存与磁盘占用更低。
- **阅读器真机高刷新率与流畅度优化**：
  - 优化阅读器在现代高刷新率屏幕上的运行表现，进入阅读器时自动匹配并激活屏幕支持的最高刷新率（90Hz / 120Hz / 144Hz 等），退出时平滑恢复。
  - 消除连续滚动与惯性滑动时的频繁界面重组，解决高帧率设备滑动阅读时的偶发掉帧与卡顿。

## 修复内容

- **阅读器无限滚动与章节边界检测**：
  - 修复短章节或特定内容下无法自动触发无限滚动加载的问题，章节末尾哨兵现在能精准触发下一章就绪请求，无需手动点击底部蓝色按钮。
- **阅读器菜单跳转与目录焦点基准**：
  - 修复连续无限滚动阅读多章后点击菜单“上一章/下一章”跳回初始进入位置的缺陷，操作栏跳转与目录高亮现统一以视口当前活跃章节为基准动态计算。
- **底栏进度条与章节名连续追踪**：
  - 修复通过菜单跳转至新章节后底栏章节名与进度百分比冻结停滞的问题，确保后续连续滚动过程中底栏信息随当前正文实时更新。
- **装扮中心与仓库卡片排版对齐**：
  - 规范装扮与徽章卡片的展示高度与舞台尺寸，彻底解决卡片参差不齐、一大一小的问题。
  - 修复部分徽章药丸圆角显示异常以及特定标识文字与图案重叠的问题。
- **下载任务状态与断点续传**：
  - 优化下载任务在网络重连和鉴权恢复后的断点续传逻辑，下载记录可正常继续与重试。
  - 完善下载完成后的文件校验与状态同步，确保系统下载目录与本地记录一致。
