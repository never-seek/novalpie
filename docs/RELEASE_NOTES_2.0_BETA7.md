# NovalPie 原生 Android 2.0 Beta 7

本次更新重点增强了原生下载体系的压缩控制与稳定性，根治了超长篇幅小说的下载超时问题，并对装扮展示与多处界面排版进行了全面规范与修复。

## 更新内容

- **原生下载压缩控制与参数配置**：
  - 在原有原生下载体系上增加插图压缩开关，支持导出 EPUB 时对正文插图进行等比缩放与画质压缩，显著减少文件占用体积。
  - 新增插图压缩质量（1%~95%）与 ZIP 压缩等级（0~9）调节，用户可根据需要自主权衡导出速度与压缩率。
  - 个人中心新增原生下载设置卡片，各项参数实时保存、开箱即用。
- **超长小说导出稳定性增强**：
  - 优化超大篇幅小说的流式拉取机制，提升连接容限与传输稳定性，彻底解决数千章节大体量正文下载时的超时中断问题。
- **EPUB 流式打包与资源归档**：
  - EPUB 归档流全面支持动态 Deflate 压缩等级，正文章节与媒体资源打包效率更高、内存与磁盘占用更低。

- **阅读器真机高刷新率与流畅度优化**：
  - 优化阅读器在现代高刷新率屏幕上的运行表现，进入阅读器时自动匹配并激活屏幕支持的最高刷新率（90Hz / 120Hz / 144Hz 等），退出时平滑恢复。
  - 消除连续滚动与惯性滑动时的频繁界面重组，解决高帧率设备滑动阅读时的偶发掉帧与卡顿。

## 修复内容

- **装扮中心与仓库卡片排版对齐**：
  - 规范装扮与徽章卡片的展示高度与舞台尺寸，彻底解决卡片参差不齐、一大一小的问题。
  - 修复部分徽章药丸圆角显示异常以及特定标识文字与图案重叠的问题。
- **下载任务状态与断点续传**：
  - 优化下载任务在网络重连和鉴权恢复后的断点续传逻辑，下载记录可正常继续与重试。
  - 完善下载完成后的文件校验与状态同步，确保系统下载目录与本地记录一致。
- **阅读器排版与界面细节**：
  - 优化长章节文字与特定排版标记的渲染表现，提升长篇阅读过程中的排版准确性。
