## EPUB

原实现只对文本使用 Deflate，图片 ZIP 条目始终 `STORED`，所以等级对图片主体不起作用；0 级文本也是 `DEFLATED` 容器，仅关闭 Deflater 压缩，和界面“仅存储”不完全一致。

- 0 级：条目实际 `STORED`。
- 1–9 级：除 EPUB 规范要求首个不压缩的 `mimetype` 外，正文、元数据和图片条目统一按所选 Deflate 等级无损压缩。
- 图片按流写入，不因为 ZIP 等级重新编码/降画质，解包后原图字节不变；另行选择的“压缩插图”仍是独立功能。
- JPEG、PNG、WebP 等通常已压缩，进一步 ZIP 压缩可能很小或无明显收益，不承诺每升一级必定变小；设置控件文案移除“体积最大/最小”的绝对承诺。
