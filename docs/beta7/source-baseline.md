| 范围 | 当前可读证据 | 剩余工作 |
|---|---|---|

| 搜索 | `auth-search*`、`guest-search`；规则/标签/字数/帮助/设置面板 | 参数真实请求与 App 映射，标签包含/排除、配置保存/恢复、管理员标签管理受控测试 |
| 论坛 | `auth-forum*`、`auth-app-post`、`guest-forum` | 页码/返回、完整编辑器格式/书卡/黑幕组合、嵌套回复/反应/投票的受控验证 |
| 书籍/目录/阅读器 | `auth-book-*`、`auth-reader`、`guest-book` | 菜单子项与下载授权、目录筛选、阅读设置各分区、真实续章/长按/分页/替换 |
| 个人/装扮/公开主页 | `auth-profile-*`、`auth-public-profile` | 部分书籍 tab 采样落在加载态，需重取；仓库、资料校验、作品/评论/签到分页与普通角色 |

## 会话安全与写入边界

- 未登录取证不退出已登录 Edge；使用公开 GET 与单独访客上下文。
- 已登录取证只复用用户提供的会话，禁止导出/打印/persist Cookie、Token、密码、完整 storage 或私信内容。
- 公开论坛资料最小化保存，过滤邮件地址、Token 形态和明显秘密赋值；不采集用户凭据文件。
- 本基线采集器只允许站点公开路由、静态资源及论坛读取接口。管理批量删除、账号变更、扣积分等不能由“遍历按钮”自动触发。
- 真实评论/下载授权测试只在实现后的明确测试场景执行，不因阅读反馈而发送回复。
