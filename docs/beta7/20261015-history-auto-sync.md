# 2026-10-15 历史记录自动同步与R2追加发布

## 用户反馈与复现

- 收藏栏读后会自动同步，历史栏不会；并要求GitHub3MB优化R2更新刚修内容。
- 根因：读后返回和底导航重新进入的dirty-progress检查只覆盖Favorites；本地更新函数在favoriteEntries不是Success时直接return，history被漏掉；retain刷新也只保留favoriteRows。
- 已建立4条失败回归：返回阅读器历史刷新、重新进入历史刷新、本地进度更新历史、历史刷新期间保留已加载多页。旧实现9tests/4failed，证据保留artifacts/beta7-history-sync-20261015/red-tests.log。

## 修复

- 历史和收藏共用读后dirtyprogress刷新规则；不需要点同步或切收藏栏触发。
- 已载入历史行先用本地真实阅读进度更新，随后正常服务器回读；不伪造没读的已读进度。
- 保留历史正在看的列表与已加载页数，后台刷新按顺序重新加载此前页，不突然只剩第一页。
- 来源接口仍是 /api/favorites/history，不把收藏接口数据冒充历史。
