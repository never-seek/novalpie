# Beta 7 用户需求与冲突决策清单

来源：本任务完整可见的用户会话（App 2.0 发起至 Beta 7 批准）、`docs/APP2_REGRESSION_AUDIT_LEDGER.md`、`agent-bridge/progress-log.md`，以及本轮网站/反馈取证。没有复制会话中曾出现的账号密码。

以下每项 Beta 7 状态均为 **pending**。旧台账的“当前 APK”只属于它所记录的旧 SHA-256，不是 Beta 7 通过证据。每项关闭时必须记录测试名、产物哈希、运行配置、截图/日志或线上回执。

## 按最后明确要求处理的冲突

| 事项 | 历史要求/误解 | Beta 7 生效要求与出处 |
|---|---|---|
| 框架 | WebView 1.x、早期原生壳、曾推荐 Flutter 阅读器 | 用户选择 Kotlin 原生深度重构；旧 WebView 仅作协议/下载参考 |
| 外观 | Fluxdo/PicaComic/Legado 结构重做与多次配色修改 | 用户最终说明“外观现在那个app做出来还行，稍微…微调”；保留当前设计，不新换主题 |
| 正文选择 | 曾通过复制正文预填替换 | 后续明确“正文阅读器文本禁止选取”；不恢复系统复制、全选或剪贴板监听 |
| 轮盘 | 网站支持选词轮盘，旧 App 只有不完整工具卡 | 用户接受不能稳定就移除；已移除，不在 Beta 7 恢复死入口 |
| 替换来源 | 曾把“全部规则”当成全站强制替换 | 当前书籍用户贡献词表；保留按书策略、设备默认和逐条屏蔽。查看全部规则不擅自开总开关 |
| 个人/公共规则 | 界面曾暗示只在“发布”才会共享 | 按实际网站创建接口说明可共享性；本机启停、标题/范围不得静默改成服务器删除或扩大全书效果 |
| 封面预览 | 曾单击或所有入口长按放大 | 搜索/书籍详情/正文/富文本图片仅静止长按预览，移动取消；收藏长按管理，上传管理不预览 |
| 下载质量 | 社区建议压缩 | 默认保留原图字节与动画，不增加强制压缩；无外部爬虫或网页下载回跳 |
| 阅读器页眉 | 旧补丁用隐藏页眉规避遮挡 | 页眉/页脚服从用户设置且占真实空间；不能靠遮正文或删设置解决裁切 |
| 横屏双页 | 个别社区建议 | 既定不新增横屏双页，但屏幕变化与系统安全区不能崩坏或丢进度 |
| 管理权限 | 调研账号为管理员 | 普通用户不能看到 admin-only；服务端最终授权，不改角色或绕过权限 |
| 发布 | 多次原地替换 Beta 6 | Beta 7 新标签/Release，保留 Beta 6；源码/提交/包/证据一致；MuMu 验收成功后才发 |

| B16 | 页面/字体/替换/图片尺寸变化重排后保持语义锚点；旧布局任务不能覆盖新结果 |
| B17 | 后台/锁屏/离开再回及进程重建恢复段落断点，不回收藏或仅章节首页 |
| B18 | TTS 应用级生命周期、generation 队列、实际朗读高亮和跟随；无引擎/失效音色/音频焦点/耳机断开有正确处理 |
| B19 | TTS 与阅读和导出使用同一替换文本；切章不读占位、不丢首句、不继续旧回调 |
| B20 | 页眉/页脚设置生效但不遮正文，工具栏显隐不得重置阅读点 |

## C. 原生导出与替换规则

| ID | 用户要求 / 验收行为 |
|---|---|
| C01 | EPUB 全流程由 App 原生授权/下载/生成/保存，不回网页 |
| C02 | TXT 原生入口保留，保存实际正文而非网页，章节完整 |

| C04 | PNG/JPEG/GIF/WebP 原始字节、画质与格式保留，默认不压缩 |

| C06 | 并发设置在“我的”/下载前可达，提供常用 8 路等和自定义；界面简洁，资源调度有上限 |
| C07 | 下载失败/暂停/重试/取消、空间不足、临时文件回收、保存阶段均明确；半成品不冒充成功 |
| C08 | 原文/应用当前替换规则两种导出；每次冻结规则快照，EPUB/TXT 实际验证 |
| C09 | 个人规则优先、公共同源去重与新旧优先；支持字面/正则/$1/启停/排序/正文或标题/章节范围 |
| C10 | 设备默认公共策略、每书覆盖、逐条屏蔽、恢复默认、复制为个人规则全部保留 |
| C11 | 普通用户可按网站合同贡献本书公共规则；个人规则同步关系清楚，本机停用不静默删除公共条目 |
| C12 | 替换仅作用文本，不改 URL、HTML 属性、插图占位；原始章节/cache 不变 |
| C13 | RE2J 安全规则，不执行公共脚本；不支持的 JS 正则语义明确提示，不能静默改变 |
| C14 | 下载独立于页面，前台服务与持久化任务检查点；后台/进程恢复可继续或明确重试，不重复扣积分 |
| C15 | EPUB2/3 目录、封面/章节/资源清单和 MIME 完整；使用支持格式的外部阅读器打开验证 |
| C16 | 下载速度分清网络、重试、解码/磁盘耗时；卡图能定位 URL 状态但不泄露授权数据 |

## 本轮后续补录原则

网站基线发现的新控件或接口逐项分配 `SITE-*` ID，并引用以上需求 ID；新社区回归分配 `FB-{postId}-{commentId}`。每条记录必须保留原意及来源，明确适用 App 或网站版本和当前证据强度；不把自动关键词分类视为人工审查完成。
