## 本轮更新

### 搜索、收藏与书籍
- **清除已保存条件不再清掉当前规则、包含/屏蔽 tag、来源、成人筛选、字数和排序**，不重置当前结果和位置。
- **新增明确的保存条件按钮**，包含/屏蔽 tag 与完整筛选一起保存；关闭自动缓存也可主动保存。清标签仅清标签。
- **补齐原生重翻章节**：书籍详情菜单和阅读器导航可选单章、多章、区间或全书；使用真实章节序号，目录未定位时不把当前章误提交为全书。
- 重翻沿用网站要求：服务端本人 API 需激活、健康且审核通过；仅本机 API 仍在工作区自助翻译。未知回执不盲重发，换代理也保留同账号在途/待确认任务的防重复记录；**提交排队不代表翻译已完成**。
- 收藏数量/总页数使用真实返回值；书籍 A→B→返回恢复各自详情、目录筛选和草稿，旧请求不覆盖新页面。

### 阅读器、TTS 与文本替换
- **增加阅读亮度及跟随系统开关**，只作用于 App 窗口，离开阅读器恢复原亮度。
- 修复重复文本段落的听书定位、旧播放回调和阅读跟随；保留系统 TTS、锁屏/后台服务、暂停恢复与跨章。
- 修复首章迟到回包覆盖后续章节/章评状态；正文手势尊重子控件点击。段落断点、音量键开关和五种翻页动画继续保留。
- 阅读、TTS、EPUB/TXT 复用文本节点替换规则，保留原文；避免改坏图片、链接或 HTML 属性。公共规则按书开关、逐条屏蔽和个人优先不取消。

### 原生下载、图片与编辑器
- **EPUB/TXT 继续由 App 原生下载保存**，保留原图/压缩选择、8路/自定义并发及原文/替换导出。
- **资料或正文图源无法确认时明确提示**：可重试或自行确认保留原文继续；不把图源读取失败当成“本来没图”，不静默宣称完整。
- 发布恢复通过任务归属与字节校验避免重复扣分授权、重复保存；取消/失败只处理本任务临时文件。
- 默认原图模式保留源文件字节；透明 PNG、GIF、动态 WebP/APNG 不因可选压缩被压成不透明静态图。**ZIP 压缩不等于图片降画质**。
- 编辑器 EPUB 导入、修改、存档与导出保留图片资源、样式/字体与元数据；损坏或缺资源明确报错。
- 修复 TXT 完成状态误写 EPUB，以及图片成功数量显示。恢复旧打包文件时保留该文件真实的完整性警告；较多插图异常的完成收据也可继续读回，不因超过旧64KiB限制卡住恢复。

### 论坛、个人页与装扮
- 改进嵌套 fold/details、黑幕内书卡/链接/图片组合；代码、转义内容不误当格式执行，发帖预览复用同一富文本。
- 回复发送中编辑的新草稿不会被旧成功回执清空；反应具体分项不由聚合赞/表情错误代替。
- 账号章节缓存隔离；资料部分保存结果明确反馈，签到结果记录防止重复请求。
- **徽章常态预览不再被 hover 样式覆盖**，保留 dot、伪元素与变量装饰，不重做整体主题。

## 与网页的区别和必要依赖

原生阅读布局、音量键翻页/开关、窗口亮度、系统 TTS 前台服务、App 管理的 EPUB/TXT 任务与恢复、公共规则本机逐条屏蔽、收藏/上传页多列网格，都是面向手机体验的增强。书籍、积分、权限、翻译结果仍来自网站；安全验证和部分复杂素材允许使用必要 WebView，**不是用整页网页替代原生页面**。

不增加外部书源/爬虫或付费云 TTS；正文不恢复复制/全选，已移除的轮盘和无效网页正文按钮不恢复。
