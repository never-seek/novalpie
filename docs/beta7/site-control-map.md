基线：Nuxt build `cbb20abd-9b37-4381-993e-3008189d738b`。静态候选逐条来源为 `20260905-public/site/control-candidates-v2.json`（2824 条含重复渲染分支）；接口候选为 `api-ledger.json`（203 条含兼容路径和动态query）。本表按业务合并控件语义，**不把合并表称为每个按钮均运行通过**。

## 当前实际接口证据

每条机器证据保留method、path、query键、响应status与脱敏schema；完整字段见对应JSON，不收集登录材料。接口审计工具不会再用GET状态给写入条目打勾。

- 搜索：`GET /api/search`（platform、adult_filter、min/max_word_count、page等）；标签：`GET /api/tags`（sort/limit/offset，多页200）。
- 阅读：`GET /api/users/me/glossaries?novel_id`、`GET /api/reader/settings`、book detail/chapters、favorites/status、reader/progress。增加规则只验证了空字段disabled→填写enabled→取消，未写入服务器。
- 个人：`GET /api/v2/users/me`、`/api/v2/users/{id}/checkins/settings`、`/checkins`、`/checkins/stats`，版本与实际字段不得降回v1。
- 新屏蔽：`GET /api/v2/users/me/blocks?page&limit`的既有浏览器200；POST/DELETE仍write-pending。
- 192→203候选变化来自提取器修复漏抓search/native fetch，不是网站新增了11个功能。

## 已确认的 App 补齐目标

1. 搜索全量标签、双端字数与直接输入、高级模式隔离、字段显示设置；默认仍按用户要求展示完整tag和指标。
2. 用户/书籍屏蔽、本人屏蔽管理；取消屏蔽保留明确状态反馈。
3. 共享替换不能被本机停用静默删除；文本节点管线保护图片/URL；导出冻结规则。
4. 原生分页/TTS/下载移出全局屏幕生命周期；长期任务不因页面离开消失。
5. 上述全站既有业务保持原生、不退化为网页链接，兼容WebView仅认证与素材。
