# NovalPie 原生 Android 2.0 Beta 5

NovalPie 2.0 是面向 [novalpie.cc](https://novalpie.cc) 用户的原生 Android 客户端。它以 Kotlin 与 Jetpack Compose 构建，重点不是把电脑版网页缩放进手机，而是把阅读、书架、搜索、论坛和个人中心做成适合触控操作的原生界面。

本版仍是公开测试版。内容、账号、积分、成人分级、管理员权限和互动权限全部以 NovalPie 源站为准；客户端不提供第三方书源、不绕过付费或权限，也不会规避 Cloudflare/安全验证。

## 先看全局：五个主页面

底部导航固定为 **收藏、搜索、工具、论坛、我的** 五个入口。进入作品、帖子、阅读器、消息或管理页后，系统返回会按原生页面栈回退，不会把上一次打开的书籍或帖子错误复用到新页面。

| 页面 | 用途 |
| --- | --- |
| 收藏 | 同步源站收藏夹、分组、阅读进度、继续阅读和更新提醒。 |
| 搜索 | 以源站参数搜索、筛选和排序作品；没有输入关键词时也会加载默认作品。 |
| 工具 | 消息、私信、工作区、上传、EPUB 编辑器、设置与按权限显示的管理工具。 |
| 论坛 | 公告、推书、交流、书评、反馈等帖子流，以及原生评论和富文本内容。 |
| 我的 | 个人资料、动态、装扮、上传作品、签到信息和其他用户公开主页。 |

## 收藏：书架、分组与阅读进度

- 同步默认收藏夹和源站收藏分组，展示真实封面、书名、作者、完整标签、收藏/阅读/字数等必要信息。
- 支持每行 **2、3、4 本** 的网格密度；标题和作者不会因为切换列数而被省略，同行卡片会为标签预留统一高度，使底部指标保持对齐。
- “继续阅读”会同时显示作品名与章节名，避免只显示章节而无法辨认来源作品。
- 阅读进度使用本地已读章节和最新目录同步：未读作品不会被错误显示为 `100/100`，读完后源站新增章节会显示可继续阅读的更新状态。
- 长按收藏书籍进入批量管理，不会在滚动中误触封面大图；书架的卡片密度、选择状态和阅读偏好会被保留。
- 列表请求失败时会显示明确失败原因和原生“重试”入口，恢复成功后不需要手动刷新网页或重启 App。

## 搜索：完整筛选、成人区与高密度书卡

- 空关键词进入搜索页时会直接加载默认作品和分页，不再出现没有内容的空白页面。
- 搜索范围支持：全部内容、仅标题、仅作者、仅标签。
- 内容分级支持：所有、仅成人、全年龄；结果由源站成人权限决定。
- 来源支持全部、NovelPia、上传；上传来源会在书籍卡片上保留对应标识。
- 搜索模式支持 AI 搜索、模糊-严格、模糊-宽松、精确匹配。
- 可使用规则、包含/屏蔽标签、字数区间、排序字段与升降序；排序字段包括相关度、更新时间、上架时间、收藏数、本站阅读量、推荐、源阅读量、字数和源收藏等源站可用维度。
- 每张搜索书卡保留封面、书名、作者、来源、完整可换行标签以及收藏/本站阅读/字数指标。多标签书和少标签书在同一行仍保持封面、标签区域和指标基线一致。
- 对高图片列表限制了滚动投机预取范围，减少封面解码挤占主线程造成的掉帧；封面原图请求尺寸和质量不因此降低。

## 作品详情：简介、目录、书评与作品关系

- 点击书籍卡片进入原生详情页，入口包含继续阅读、加入/取消收藏、下载、目录和评论。
- **简介、目录、书评** 使用互斥标签页：一次只展示一个内容区，不再把三块内容堆成长页面。
- 简介页展示封面、作品名称、作者、完整标签、简洁的本站/源站统计与简介文本；统计压缩为易读信息，不挤压正文和操作按钮。
- 目录页按源站章节数据展示，支持直接跳章、当前阅读位置回到正文、目录筛选和章节状态识别。
- 作者名和标签均可直接进入对应搜索结果，便于查看同作者或同标签作品。
- 书评页支持根评论、嵌套回复、点赞/点踩、表情、奖励等源站允许的互动；是否可操作取决于当前登录状态和源站权限。
- 作品封面使用统一原图预览机制：卡片默认展示源站外层图，静止长按才打开大图；GIF、Animated WebP 和幻影坦克类内层图会按原始资源显示。滑动超过触控阈值会取消长按，避免翻列表时误放大。

## 原生阅读器：连续阅读、分页与可调排版

阅读器是 2.0 的核心模块，章节正文由原生界面承载，不依赖“网页正文”按钮回退。

### 阅读方式与章节导航

- 支持普通连续滚动、无限滚动和分页阅读。
- 无限滚动会在章节末尾自动接入下一章；正文、章节评论、下一章正文保持正确顺序，继续加载不会清掉已经出现的章评。
- 分页模式在章节最后一页会自动进入下一章；在下一章开头向前翻页可回到上一章最后一页，而不是只回退一页。
- 中央单击稳定显示/隐藏工具栏；正文再点一次可隐藏，不要求双击，也不会在滑动时自动弹出。
- 工具栏包含返回书籍、目录、上/下一章、布局/主题、设置、全屏、导航等真实原生操作；无效的“网页正文”入口已移除。
- 底部章节标题和进度会跟随当前可见章节更新，不会在跨越多章后仍停留在初始章节。

### 排版与个性化设置

- 可调整字体、字号、行距、段距、边距、背景、主题、亮度、图片显示和全屏等阅读参数，并保存偏好。
- 提供正文查找与全文替换，适用于源站正文中的统一文本修正需求。
- 翻页动画可选：无动画、淡入、覆盖、滑动、仿真；不喜欢动画时可明确选择无动画。
- 音量键翻页可单独启用或关闭。关闭后，音量键恢复为系统音量控制。
- 听书入口可在阅读设置中开关。关闭后入口会完全消失；设备没有配置 Android TTS 引擎时，App 会提示原因并可跳转系统文字转语音设置。
- 系统返回、阅读器返回和书籍详情返回遵循同一原生栈，不会污染收藏页、论坛页或其他作品详情。

### 章节评论与正文图片

- 可在阅读器中查看章节评论、展开回复和按源站权限参与互动；“打开网页评论”只保留给评论网页能力，不替代正文阅读。
- 正文内图片支持原始尺寸加载、GIF、WebP 和长按大图预览；预览界面支持缩放、拖动和双击复原，底部内容不会被裁切。
- 正文连续加载、目录定位和评论请求使用独立状态，某一请求慢或失败时不会让整页永久失去响应。

## 原生下载：EPUB 与 TXT

- EPUB 与 TXT 均由 App 在 Android 下载目录中直接生成，不会把用户踢回浏览器网页下载。
- 下载前可选择图片并发数：2、4、8、12、16 路，也可以填写任意正整数的自定义并发。该设置会实际传给下载器，而不是只改变显示文本。
- EPUB 按章节写入，包含封面、目录、章节 XHTML、OPF/导航结构和正文插图；图片以源文件字节和原始媒体类型保存，不主动压缩图片质量。
- 源正文中同一图片的多次出现会按出现位置保留，不会因为 URL 或哈希相同而错误删除；封面与正文插图分开处理，避免额外重复插图。
- 大书下载使用私有临时文件，完成并校验后才发布到下载目录；可显示进度、暂停、继续、取消、失败原因和重试入口，取消后会清理本轮临时文件。
- 如果源站要求积分、确认或账号权限，仍先按照源站提示确认；App 不会绕过这些限制。

## 论坛：公告、推书、交流、书评与反馈

- 论坛主页面提供公告、推书、交流、书评、反馈五个分类，横向布局适配窄屏，不会全部挤在左侧。
- 帖子卡片显示作者、头像/头像框、发布时间、标题、置顶/精华标记、正文摘要、回复数、互动数和浏览数据。
- 单次稳定点按可打开帖子；滑动列表不会误开详情。返回论坛后再打开另一条帖子，不会复用上一帖内容。
- 支持新建帖子、根评论、回复、回复的回复。提交成功后会即时插入并重新拉取验证；失败时保留草稿、回复对象和请求标识，便于用户重试。
- 评论编辑器提供源站语法输入工具，包括粗体、斜体、标题、引用、代码、链接、列表、下划线、删除线、黑幕剧透和折叠。
- 点赞、点踩、表情、奖励等互动会按源站登录状态、积分和权限呈现；不可操作时不会伪造成功状态。

## 富文本、剧透、折叠、链接和分享书卡

- 原生内容渲染支持普通 Markdown/HTML 常用格式：加粗、斜体、删除线、下划线、引用、代码、标题、列表和长链接。
- **剧透黑幕**默认遮挡内容；可点按单段黑幕揭示，也可在偏好中开启“显示剧透”。该偏好同时应用于论坛、书评、章节评论、个人动态和公开主页动态。
- `[fold:标题]...[/fold]` 折叠内容默认收起；展开后其中的文字、链接、图片和书籍卡片仍可正常互动。
- 评论中的站内书籍分享代码，例如 `[bookid:350192]`，会加载成带封面、书名、作者、标签与指标的原生可点书卡，而不是裸代码。
- Markdown 图片、`<img src>`、`data-src` 懒加载图片、GIF 与 WebP 会作为原生图片块展示；图片长按可查看原图。
- 站内书籍、帖子、用户主页等链接会尽量走原生路由；外部链接按 Android 外部打开规则处理。

## 我的：资料、动态、装扮、上传与公开主页

- “我的”页同步头像、头像框、昵称、等级、简介、已装备徽章、统计信息和账号相关操作。
- 动态提供全部、帖子、评论、书评、章评等分类；某类确实没有数据时会显示明确空态，切回全部仍可恢复真实动态。
- 装扮/背包会加载每个 badge 自己的真实预览资源，包含图片型、CSS 型、WebP 与 GIF，不再把不同物品显示为相同占位图。
- 头像框以外层叠放方式显示在头像周围，已装备 badge 会出现在个人资料区域。
- 上传书籍管理使用紧凑卡片，支持 2/3/4 列；保留封面、书名和作者，不因卡片美化丢掉管理信息，也不会长按预览管理页封面。
- 进入其他用户主页可查看公开资料、作品、评论、书评、动态、签到统计和签到记录；页面各分区独立加载，单项失败可重试，不会让整页卡死。

## 工具：消息、工作区、创作与设置

- **消息中心**：查看站内消息、消息详情、私信会话和消息设置；站内链接可继续跳转对应原生页面。
- **工作区**：保留源站工作区入口和相应原生导航，适合需要管理网站功能的用户。
- **上传书籍 / EPUB 编辑器**：提供上传作品、编辑作品信息、章节管理、追加章节和 EPUB 编辑相关入口；实际可用能力仍受账号权限和源站接口限制。
- **术语表与应用设置**：可管理阅读、搜索、显示、网络/代理等本地偏好。
- **管理员工具**：管理后台、内容审核、密钥管理、操作日志、抓取管理、商店管理等只会对源站识别为管理员的账号显示。普通账号不会看到或保留这些入口。

## 登录、安全验证、网络与隐私

- 登录、注册、找回密码和安全验证均按源站流程处理。安全验证使用保留会话的网页回退页，而不是把账号密码或 Cookie 写进说明文件、日志或客户端配置。
- 验证码页加载期间会显示原生加载状态，取消验证或系统返回后个人页会重新请求资料，不再停留在永久空白或“正在同步”状态。
- App 使用当前源站会话决定成人内容、评论、积分确认、下载、管理员能力与个人资料；这些结果不会被客户端伪造或放宽。
- 可在应用设置中配置代理。MuMu 等模拟器可通过 `adb reverse tcp:7890 tcp:7890` 使用宿主机代理；真实手机应填写实际可访问的代理地址，客户端不会默认把真机流量错误指向设备自身的 `127.0.0.1`。
- 覆盖安装同一 Debug 签名版本会尽量保留登录态、阅读进度、收藏设置、搜索偏好和已下载文件；不要为了刷新问题随意清除 App 数据。

## 稳定性、适配和测试情况

- 对 360dp 窄屏验证过搜索、收藏和作品详情的书籍指标、标签、按钮和卡片对齐，避免字数等数据被裁切。
- 输入法打开后关闭时，列表高度会恢复，不应在底部留下大面积空白。
- 论坛、书籍详情、公开主页和搜索采用请求新鲜度与分区加载策略，避免快速切换 A→返回→B 时显示旧 A 内容。
- 图片滚动性能通过控制预取范围优化：在同一 MuMu 对照下，搜索高图列表的 UI 帧耗时从明显卡顿降至可用水平；网络本身慢或模拟器首次启动的开销仍可能影响首屏速度。

## Beta 版边界与已知环境限制

- 这是 Debug 签名的公开测试包，不是应用商店正式签名包。
- Cloudflare/安全验证必须由用户本人完成；客户端不会读取、保存或代填真实账号密码、浏览器 Cookie 或验证码。
- 听书的真实播放、暂停和跨段朗读依赖设备安装并启用 Android TTS 引擎。没有引擎时，客户端只能提示并引导到系统设置。
- 网络、源站接口、图片站、成人内容可见性、积分确认、评论/打赏权限和管理员入口都可能随源站或账号状态变化。
- 仍欢迎反馈真实问题。请尽量提供作品/帖子链接、复现步骤、截图、设备型号、Android 版本、网络/代理情况；不要仅描述“打不开”。

## 安装与升级

1. 下载本 Release 的 `NovalPie-native-2.0.0-beta5-debug.apk`。
2. 在 Android 系统允许当前来源安装 APK 后直接覆盖安装；若系统提示签名不一致，不要立刻卸载旧 App，以免丢失本地会话、阅读记录和下载文件。
3. 首次打开后按 NovalPie 网站正常登录。遇到安全验证时，在 App 的网页回退页完成验证后返回原生页面并刷新。
4. 如果使用 MuMu 本地代理，先确认 `adb reverse tcp:7890 tcp:7890` 已建立；真实手机请在 App 设置中填写可访问的代理地址。
