# NovalPie 原生 Android 2.0 Beta 5

Beta 5 是面向 [novalpie.cc](https://novalpie.cc) 已登录用户的公开测试版。客户端以 Kotlin 与 Jetpack Compose 原生实现书架、搜索、作品详情、论坛、个人页、阅读器和下载流程；网页登录安全验证与少数未原生化能力仍会在保留会话的网页回退页中完成。

本项目遵从源站账号、权限、积分与内容规则：它不提供第三方书源、绕过收费、绕过权限或规避网站安全验证的功能。

## 本次重点更新

### 阅读器与阅读记录

- 修复阅读器工具栏的中央点按显示/隐藏、目录、系统返回和书籍详情返回链路，移除无效的“网页正文”入口。
- 连续滚动、无限滚动与分页阅读均可跨章节前进；分页模式可从下一章返回上一章末尾，连续阅读时底栏会随当前可见章节更新。
- 保留章节评论在无限滚动中的正文—章评—下一章顺序，不会因自动续章丢失评论区。
- 补全全文替换、翻页动画（无动画、淡入、覆盖、滑动、仿真）、音量键翻页及其开关、字体/字号/行距/边距/主题/背景等设置。
- 听书入口会随设置关闭而完全隐藏；设备未配置 TTS 引擎时会给出明确提示并能跳转系统设置。

### 书架、搜索与作品页

- 收藏、搜索和上传管理支持 2 / 3 / 4 列书籍卡片；卡片保留封面、书名、作者和必要数据，同行底部指标保持对齐。
- 收藏进度按实际阅读记录与当前目录同步，显示作品名、已读章节和更新提醒，不再把未读作品错误标为读完。
- 搜索页未输入关键词时会加载默认作品；搜索范围、成人分级、来源、规则、标签、字数、模式与排序继续映射源站参数。
- 书籍详情将简介、目录、书评改为互斥分页；压缩源站/本站统计占用，同时保留完整标签、作者与标签跳转搜索。
- 卡片封面与正文插图使用统一原图预览：静止长按显示大图，滚动会取消预览；支持 GIF、Animated WebP 和幻影坦克类外层/内层图像展示。

### 论坛、书评与富文本

- 论坛、书评、章节评论支持根评论、回复和回复的回复；失败时保留草稿和回复目标以便重试。
- 原生渲染加粗、斜体、删除线、下划线、代码、引用、列表、链接、折叠、剧透黑幕与 Markdown/HTML 图片，避免把源语法直接显示给用户。
- 剧透默认遮罩，单段点按可揭示；“显示剧透”偏好会同步应用于论坛、书评、章评和动态。
- `[bookid:书籍 ID]` 分享内容会显示为可点击的原生作品卡片；评论中的长链接、懒加载图片、GIF 与 WebP 可打开并支持原图预览。

### 下载、个人页与稳定性

- EPUB 与 TXT 均由 App 在 Android 下载目录中原生生成，不会把下载流程跳回网页。
- EPUB 下载以临时文件完成后再发布，保留正文图片出现次数、原始媒体格式与封面；下载前可选择常用并发档位或自定义并发数。
- 个人页、公开主页、动态、上传书籍、头像框和背包装扮按源站数据加载；管理员工具会根据当前账号权限显示。
- 网络加载改为分区处理：书架、论坛评论和公开主页单个请求失败时可重试，不再因一个慢请求锁死整页。
- 优化高图片列表滚动时的投机预取，降低图片解码与主线程争用造成的卡顿。

## 已知环境限制

- Cloudflare/安全验证必须由用户本人在网页验证页完成；客户端不会读取、保存或代填账号密码、Cookie 或验证码。
- 真实朗读依赖设备已配置的 Android TTS 引擎；未配置时客户端只能验证错误提示与系统设置跳转。
- 网络连通性、成人内容可见性、管理员入口、积分确认及评论/打赏权限均由当前源站会话和账号权限决定。

## 安装

1. 下载本 Release 的 `NovalPie-native-2.0.0-beta5-debug.apk`。
2. 在 Android 系统允许当前来源安装 APK 后覆盖安装。覆盖同一 Debug 签名可保留本地登录态、阅读记录、设置和下载文件；不要为了刷新问题随意清除应用数据。
3. 打开后按源站正常登录。遇到安全验证时，在网页回退页完成验证后返回 App 并刷新当前页面。
4. 反馈问题时请附上作品/帖子链接、复现步骤、截图、设备型号、Android 版本与网络/代理信息。
