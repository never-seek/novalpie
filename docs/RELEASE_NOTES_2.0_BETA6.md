# NovalPie 原生 Android 2.0 Beta 6

本次重点是把阅读器的“替换规则、下载导出、断点续读”做成可控、可验证的原生能力。

## App 额外提供的能力

- **公共替换规则可按“单本书”开启或关闭，也能逐条屏蔽不想要的公共规则。** 不再因为查看“全部规则”就自动改正文；默认只应用“我的规则”。
- **每本书都可以恢复跟随你的默认规则设置。** 临时开关一键撤销，不会留下难以理解的独立状态。
- **原生 EPUB/TXT 下载可选“原文下载”或“应用当前替换规则”。** 选择替换版时，下载开始瞬间冻结规则；网站原文、阅读缓存和图片 URL 不会被改写。
- **EPUB 由 App 本地生成并显示章节/插图进度。** 支持暂停、继续、取消、重试与下载并发设置；正文插图和封面按原始字节保留，不压缩、不丢图。
- **同章断点续读会记住具体段落位置。** 从目录返回、切后台或 Android 回收进程后，会恢复到同一段附近，而不是回到本章第一页。

## 阅读器改进

- 支持 HTML / Markdown 的粗体、斜体、下划线、删除线；叠加格式不会重复正文。
- “内容宽度”已归入“布局”，不再混在排版设置里。
- 章节评论默认可折叠；原生阅读进度会同步回网站。
- 繁体 / 简体 / 原文模式会覆盖正文与阅读器界面文本。
- 书籍详情的低频管理操作已收进底部菜单，减少简介页误触。

## 与网页的边界

- App 使用同一个 NovalPie 账号、书架、搜索、正文、评论和阅读进度；它不是网页壳，但网页仍是数据和权限的来源。
- 为避免公共词表强制影响阅读，App 默认不应用公共替换规则；需要时由读者为某本书显式开启。
- 横屏双页阅读暂未加入；需要 Android 系统已安装可用的 TTS 引擎才能实际发声。

## 验证

- Debug / Release 单测各 818 项通过，Lint 无问题。
- 在 MuMu 上实际生成并校验了替换版 TXT 和 1.5GB 级 EPUB；`unzip -t` 通过，章节和插图引用完整。

## 安装

下载 `NovalPie-native-2.0.0-beta6-debug.apk` 后直接安装即可。已装 Beta 5 的用户可覆盖安装，登录态和本地设置会保留。
